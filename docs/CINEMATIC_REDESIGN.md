# MRK cinematic homepage redesign

## Scope and source

The supplied homepage reference informs the navy hero, ruby accents, platinum content, diagonal editorial imagery, pricing banner, split quote section and closing truck scene. All text and controls remain HTML. Existing transparent branding and photography sources are reused; dedicated smaller AVIF/WebP derivatives are generated by `scripts/optimize-cinematic.mjs` without changing the original assets; no new image generation, framework migration or runtime dependency was introduced.

The exact dusk riverside truck composition in the supplied reference is not available as a separate asset. The implementation composes the existing `adelaide_moving_day_hero_banner` and dedicated mobile crop with navy atmosphere, independent ruby trails and motion. Existing twilight street artwork supplies pricing, quote and coverage imagery. These existing images are concept artwork, as recorded in `assets-src/photography/mrk-site-graphics/README.txt`; they are not evidence of specific employees, fleet or completed jobs.

## Preserved behavior

- All 24 prerendered routes, canonical metadata, structured data and indexing controls.
- One quote submission path through the existing QuoteForm and `/api/quote`; backend, spam checks, provider confirmation, retry key, fallback and storage protections are unchanged.
- All existing FAQs, six approved services, seven approved service regions, phone and email.
- GST, 3-hour minimum, 1-hour call-out fee and individually confirmed truck, crew, inclusions and other charges.
- Optional inventory builder and its quote prefill behavior.
- Footer legal navigation and AB Web Studio attribution.

## Motion and accessibility

Finite truck and text entrances, pointer-responsive desktop hero depth, restrained atmospheric ribbon movement, travelling light highlights, IntersectionObserver entrances on all engines, image depth on supporting view-timeline browsers, button elevation, card and arrow interaction, keyboard coverage tabs, disclosure navigation and animated FAQ expansion. Content is visible before initialization and without JavaScript. Reduced motion disables entrances and parallax and uses immediate quote/navigation scrolling.

The mobile menu is a disclosure, not a modal. Collapsed links are inert; Escape returns focus to its trigger. Coverage tabs support arrows, Home and End. Collapsed FAQ answers are inert. Mobile call/quote actions hide when the quote form intersects the viewport.

`e2e/theme.spec.ts` retains the bright page-canvas and contrast guards. Its former blanket prohibition on dark panels is replaced with an explicit allowance only for the cinematic sections and site chrome required by this brief. `e2e/cinematic.spec.ts` adds composition, keyboard coverage, homepage failure/retry/delivery and actual animation checks. Screenshot capture waits for image decoding so lazy imagery is included.

## Release boundary

Feature branch based on current `main`. Existing checkout modifications were line-ending-only when inspected with `git diff --ignore-space-at-eol`; unrelated files remain untouched. No production merge, deployment, domain change, indexing change or live customer enquiry is part of this handoff. Provider acceptance is exercised with mocked browser responses and unit tests; live inbox delivery and real Redis integration require their external configuration and are reported separately.

## Results

Measured results, repeatable validation commands and remaining limits follow.

The first mobile Lighthouse run exposed expensive blur/filter work during motion and oversized image transfers. Optimization removes blur from mobile controls and trust tiles, shortens the finite truck entrance, removes filtering from the animated trail parent, reduces redundant display font weights, and serves new quality-45 AVIF variants from existing original artwork. Responsive image preload source sets now match the actual picture source sets, avoiding a duplicate mismatched hero preload. Header blur remains on desktop; mobile keeps its navy sticky contrast and active entrances, scroll reveals and interactions.

### Code review

Reviewed navigation modifier-key behavior, observer/animation cleanup, reduced-motion handling, keyboard tab selection, FAQ visibility, quote preset synchronization, image source sets/preloads and approved claim boundaries. No backend or business configuration changes. The mobile quote target retains the existing `quote-section` ID. Screenshot output is separated by browser project to avoid concurrent file overwrites. Browser concurrency is capped at two for reliable multi-engine verification on Windows/WSL.

The navigation-to-quote mobile overlay defect was reproduced with a regression test that waits for homepage hydration before navigating. The footer observer now resubscribes when the route changes, so the floating actions hide for the current form as well as the initial one.

Validation used the existing Windows Node 24 installation via PowerShell from WSL. `npm ci` completed with zero reported vulnerabilities. The initial Linux sharp failure was caused by Windows-native dependencies in the mounted checkout; using the matching Windows runtime resolved it without dependency or lockfile edits.
